Silent Payments shell — labeled accounts, no node.

## Features

- BTC path m/352'/0'/0'
- Deterministic digest (stdlib, no crates)
- Vault + account derive
- cargo test covers keys and wallet

## Prerequisites

- Rust 1.75+
- Git

## Getting Started

```bash
git clone <repo-url>
cd silent-payments
cargo build --release
./target/release/silent-payments --help
```

## Tests

```bash
cargo test
```
